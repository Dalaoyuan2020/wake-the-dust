# 哑铃专题资料（已核对）

检索日：2026-09-29。只记能点开源文的条目。

## 我们要拿的结论（先读这三行）

1. **外挂 IMU 计次数在学校课设 / 专利 / 商品里都被做通了**，不需要自研算法。
2. **商品死在「改旧铁 + 灵魂」**，不死在传感器。
3. **装法比芯片更容易败**：胶贴会飞；夹架 / 绑带 / 旋到露出杠是现成做法。

## A. 最像我们的开源 / 课设

### 1. Illinois ECE 445 Smart-Clip（2026 春）

- PDF：https://courses.grainger.illinois.edu/ece445/getfile.asp?id=25408
- 结题 PDF：https://courses.grainger.illinois.edu/ece445/getfile.asp?id=25865
- 海报：https://courses.grainger.illinois.edu/ece445/getfile.asp?id=25698

做什么：夹在哑铃 / 杠铃上的小夹。ESP32-S3 + MPU-6050，蜂鸣器报形，BLE 发 reps + wobble。

他们写死的指标（可当我们测试清单）：

- 清洁动作 9/10 不误报
- 报完一下 200ms 内有反馈
- 5 米内 BLE 100% 到 App
- 一组 10 下夹子转角 < 10°

算法：偏差 > 3.0 m/s² 开始一下，回落点算 1 rep。两条 BLE 特征：50Hz 原始流 + 结束才发次数。

**我们拿：夹架 + 偏差阈值计次数。不拿：形态 / 50Hz 流到小程序（微信 MTU 吃不消）。**

### 2. Codejam 2025 SmartBell

- https://github.com/Redcowbois/Codejam-2025

传感器装在哑铃 **底部**，检测是否还在地上。一离地自动开始一组。STM32 + MQTT + 画面识别动作。

**我们拿：「离座 = 开始」。黑客松用座上微动开关比 IMU 识动作稳。**

### 3. gym-imu（VBT）

- https://github.com/FedericoPacheco/gym-imu

XIAO **ESP32-C3** + MPU6050 + 3D 壳 + 手机 App。做的是速度微训，不是闲置记录。板型和装配跟我们很近（我们用 nRF 是为了睡眠电流）。

### 4. mpiseno / 10PD Smartbell

- https://github.com/mpiseno/Smartbell 串口记录，星标 0
- https://github.com/10PD/Smartbell 树莓派 + 神经网给触觉反馈，星标 0

证明「智能哑铃」学生项目很多，几乎没人用。不要把规模当成验证。

## B. 论文与专利（计数怎么算）

| 条目 | 做了什么 | 对我们 |
|---|---|---|
| CN117883764A [链接](https://patents.google.com/patent/CN117883764A/zh) | 6 轴、**50Hz**、合轴、带通、积分、脉冲匹配、余弦相似度判重复动作 | V1 可以加带通+合轴；V0 的峰值已经够 |
| MSSE 2016 手腕计哑铃动作 | 低通 + 变差最大轴的峰值检测，12 种动作分类 | 证明峰值计次数在学术上站得住 |
| LEAN 2023 Sensors | 手表实时计次数 + ROM | 记人不记铁 |
| W8-Scope | 装在器械配重堆上 | 不是自由铃 |
| IEEE 2025 哑铃 IoT | MPU6050 装在哑铃上 + RFID 认人 | 形态跟我们一样，没灵魂 |
| PUSH Band / Beast | 前臂或杠上 IMU，专业 VBT，约 250 英镑 | 不同用户 |

专利里写明的采样：**50Hz**。我们 V0 的 `loop()` 要比这快，不要加太长 delay。

## C. 商品（硬件竞品实拍）

### 米家智能哑铃（2025-01 众筹）

- 新浪科技 / 锋潮：众筹 **99 元**起，零售约 **129 元** 一对 1kg
- 六轴 IMU 在 **一只** 里；LED 点阵屏显次数 / 时长 / 热量
- 两节 7 号电池，宣传 **177 天**
- TESTV：太轻；动作不标准也会被记（可以作弊）；综合 7.5
- 什么值得买深度测：课程比硬件有用

**对我们：** 路径验证了；它不改你家 10kg；可作弊跟我们 V0 一样，黑客松不要脸红。

### FED DT1（官网 2026-09 抓）

- https://www.fedfitness.com/products/smart-bluetooth-dumbbell-tracker-with-app
- **35 USD**，预售，官网写 mid-October 到货
- 胶贴版净重 **21.9g** + 底 11.9g；螺纹版 32.7g
- 尺寸 **3 × 4 × 2 英寸**（约 76×102×51 mm，比 XIAO 大得多）
- Bluetooth **4.2**，写 6-Axis Gyroscope（应是 IMU）
- 连续用 **60 小时**（说明他们不睡死，或者连着 App 才这么耗）
- 装法：平面胶 / 旋到露出杠
- Wayfair **0 评价**
- YouTube：控制动作能记；用猛不稳

**对我们：** 这是全球唯一已上市的「贴到你自己的哑铃上」。差异化不要讲准，讲灵魂和吃灰。我们壳要比 76mm 短。

## D. 装在哑铃哪里

| 位置 | 谁在用 | 利 | 弊 |
|---|---|---|---|
| 六角端面 | DT1 胶贴 | 不挡手 | 用猛飞 |
| 露出杠纹 | DT1 螺纹 | 牢 | 家用六角铃常没有露纹 |
| 手柄夹 | Smart-Clip | 换铃快 | 碰手、转角 |
| 底部 | Codejam SmartBell | 离地一眼看清 | 放下碰到 |
| 手腕 | 论文 / PUSH | 不改铃 | 记人不记铁，和标题偏 |

家用六角铃推荐：**端面泡棍绑带 + 3D 浅壳**，别用双面胶当主方案。
